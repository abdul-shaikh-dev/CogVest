# Play Store Listing Draft

## Short Description

Local-first portfolio tracker for INR investments and investing behaviour.

## Long Description

CogVest is an Android-first portfolio tracker for crypto, Indian stocks, ETFs, and cash. It helps you track holdings, portfolio value, allocation, cash, and trade context locally on your device.

V1 is local-first. Portfolio records use CogVest's app-private Android storage
and are excluded from Android cloud backup and device transfer. There is no
login, backend, cloud sync, analytics, or brokerage integration. Quote services
receive only asset identifiers such as ticker or coin ID.
