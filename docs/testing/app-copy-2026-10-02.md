# App copy review

Reviewed on 2 October 2026, starting from merged main `6a896f8`.

## Changes

Applied the requested Unslop pass to on-screen wording across setup, imports,
asset and transaction review, Cash, Progress, PPF, Futures, insights, settings,
backup, and recovery. Removed repeated local-only subtitles and replaced
internal terms with plain descriptions. Clear labels were left unchanged.

For example, "Replayed wallet" is now "Wallet from recorded activity".
The holdings import explains starting quantities and average costs instead of
"aggregate opening positions" and "one atomic save". Privacy details state
the encryption limitation without referring to an internal product version.

No asset-name shortening, layout redesign, calculation, schema, provider, or
storage changes. Currency, estimate, tax, backup, and deletion warnings remain.
Historical design and test evidence was not rewritten.

## Verification

- `npm run test:v1:pc` passed. TypeScript passed, 185 suites and 1,904 tests
  passed, and Expo doctor passed 17/17 checks. One suite and three tests retain
  their existing skips. Android readiness and strict smoke checks passed.
- Built and installed a fresh standalone release APK with the existing private
  emulator QA key. No Metro connection, cloud build, tag, or public release.
- `maestro test -e SHOT=normal e2e/visual/app-copy.yaml` passed.
- `maestro test -e SHOT=narrow-large-text e2e/visual/app-copy.yaml` passed.
- Inspected setup, holdings import, transaction import, backup export, expanded
  privacy settings, and PPF account entry in both display configurations.
  Copy wraps without clipping in the settled captures. Some rapid-navigation
  captures had incomplete redraws; those screens were recaptured after a
  three-second wait before review.
- The native flow asserts the backup encryption warning, possible document
  provider sync, and the distinction between holdings and transaction imports.
  It does not create or remove portfolio records.

The emulator was `CogVest_Perf`, `emulator-5554`, Android API 36, x86_64.
Normal configuration was 1280x2856 at 480 dpi with font scale 1.0. The narrow
configuration was 1080x2400 at 480 dpi, or 360 dp wide, with font scale 1.3.
Display size and font scale were restored after verification.
